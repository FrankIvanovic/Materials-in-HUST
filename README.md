# 《电磁场与电磁波》课程论文

基于毕奥–萨伐尔定律的经颅磁刺激（TMS）磁线圈磁场计算、MATLAB 数值仿真与有限元仿真对比分析。

## 论文要求

课程论文需包含以下七个部分：

1. 简介
2. 理论分析与计算模型
3. 运用 MATLAB 进行计算及代码
4. 结果分析
5. 仿真软件仿真磁场及结果对比分析
6. 结论
7. 参考文献

**提交物**：程序代码（或软件代码）、程序运行说明、课程论文，共三部分。

**组织方式**：按学号顺序 4–6 位同学选一个线圈，每人单独完成，组内不抄袭，设组长分工。

## 计算思路

- 将线圈绕组离散为电流元，由毕奥–萨伐尔定律叠加求解空间磁场分布：
  **dB = (μ₀/4π) · I dl × r̂ / r²**
- MATLAB 数值计算：绘制线圈三维模型、轴线/截面 B 分布、聚焦性对比。
- 有限元软件（COMSOL / Ansys Maxwell / FEMM）仿真对比，验证数值结果。
